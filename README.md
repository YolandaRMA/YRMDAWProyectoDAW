# Despliegue de Aplicaciones Web

**CFGS Desarrollo de Aplicaciones Web · 2.º curso**

Repositorio dedicado a la asignatura de **Despliegue de Aplicaciones Web**, correspondiente al segundo curso del ciclo formativo de Desarrollo de Aplicaciones Web.

En este espacio se recopilan los contenidos, prácticas, documentación y recursos utilizados durante el desarrollo de la asignatura, organizados por unidades de trabajo.

## Contenido de la asignatura

| Unidad | Contenido |
|:---:|---|
| UT1 | Arquitectura Web. Implantación, configuración y administración de servidores web. |
| UT2 | Implantación, configuración y administración de servidores de aplicaciones. |
| UT3 | Servicios de red implicados en el despliegue de aplicaciones. |
| UT4 | Control de versiones. |
| UT5 | Documentación. |

## Documentación destacada

- **[Guía del servidor de desarrollo](Guia_ServidorDesarrollo.md)** – Documentación relacionada con la preparación y configuración del entorno de desarrollo.

## Organización del repositorio

Los contenidos se distribuyen siguiendo las unidades de trabajo de la asignatura, facilitando su consulta y seguimiento a lo largo del curso.
